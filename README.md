新能源充电桩系统

引言
随着新能源汽车产业的快速发展，对于充电桩管理和智能充电的需求日益增长。本项目旨在打造一套基于`uni-app`开发、可打包为安卓APK、覆盖主要平台的智能充电桩管理系统。系统涵盖用户端与后台管理，适合校园、社区、写字楼等多场景应用，促进绿色出行和智能能源管理。

技术方案
- 前端：采用 `uni-app` 跨平台框架开发，一套代码打包安卓/微信小程序等多端。
- 后端：Node.js（Express）/ Python（Flask/FastAPI）任选，推荐 RESTful API 风格。
- 数据库：MySQL 或 MongoDB 支持关系型与非关系型数据需求。
- 部署：服务器可选云主机，安卓端通过 APK 安装，支持远程 OTA 升级。

角色划分
- 用户：注册/登录，个人充电，账单管理，实时查看充电状态。
  管理员：充电桩信息维护，订单管理，用户管理，数据统计与分析。
- 运维人员：设备巡检、远程故障诊断、维护日志管理。

需求分析
1. 用户端功能
    - 充电桩扫码/地图定位
    - 充电时长及费用显示
    - 支付、账单和历史记录
    - 实时充电状态监测与控制（开/停）
    - 消息/异常推送

2. 管理后台功能
    - 充电桩状态管理及批量导入
    - 订单和收入统计
    - 用户和权限管理
    - 故障报警及处理
    - 数据可视化报表

3. 运维管理功能
    - 设备远程控制
    - 故障处理与工单流转
    - 维护巡检签到

## 数据库三线表设计（核心表结构）

1. 用户表 user
| 字段名     | 类型     | 描述           |
|:---------:|:--------:|:--------------:|
| id        | int      | 用户唯一ID      |
| username  | varchar  | 账号            |
| password  | varchar  | 密码（加密）    |
| role      | tinyint  | 角色（0用户、1管理员、2运维）|
| phone     | varchar  | 手机号          |

2. 充电桩表 charging_pile
| 字段名         | 类型     | 描述          |
|:-------------:|:--------:|:-------------:|
| id            | int      | 唯一ID        |
| location      | varchar  | 地理位置      |
| code          | varchar  | 设备编号      |
| status        | tinyint  | 状态(在线、离线、故障等) |
| last_maintain | datetime | 上次维护时间  |

 3. 充电订单表 charging_order
| 字段名      | 类型     | 描述           |
|:----------:|:--------:|:--------------:|
| id         | int      | 订单ID         |
| user_id    | int      | 用户ID         |
| pile_id    | int      | 设备ID         |
| start_time | datetime | 充电开始       |
| end_time   | datetime | 充电结束       |
| status     | tinyint  | 订单状态       |
| amount     | decimal  | 金额           |

4. 运维日志表 maintain_log
| 字段名      | 类型     | 描述           |
|:----------:|:--------:|:--------------:|
| id         | int      | 日志ID         |
| pile_id    | int      | 设备ID         |
| staff_id   | int      | 运维人员ID     |
| desc       | text     | 故障/维护说明  |
| time       | datetime | 维护时间       |

系统逻辑架构图（简要建议）
1. 用户端 <--> API服务 <--> 数据库
2. 管理后台 <--> API服务 <--> 数据库
3. 充电桩设备 <--> API服务（上传状态、接受启停命令）

模块列表（可自定义与扩展）
- 用户认证与授权（JWT/token机制）
- 地图与设备扫码查找充电桩
- 支付（支付宝/微信/小程序支付接口）
- 远程充电控制（开启、暂停、停止）
- 充电进度及告警推送（Websocket/Socket通信）
- 管理员可视化仪表板（数据大盘、订单、收入统计等）
- 设备运维工单流转和日志
- 数据分析与能耗优化创意模块

创意亮点
- 个人碳减排量排行&激励
- 微信/支付宝小程序同步上线
- 充电预约&抢桩
- 预测性维护（根据充电桩状态及历史运行数据，自动下发维修提醒/工单）
- AI算法推荐附近空闲/高效充电桩

快速开始
1. 克隆项目仓库
2. `npm install` 安装依赖
3. 配置数据库/后端API地址
4. `npm run build:app-android` 打包安卓APK
5. 启动后端，注册管理员并添加充电桩测试数据
